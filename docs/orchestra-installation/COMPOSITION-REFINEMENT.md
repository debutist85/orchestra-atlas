# Prototype 01A composition

## Active geometry: polar lattice

Prototype 01A uses one deterministic polar lattice generated by
`generatePolarGrid()` in `seating.ts`. Its configuration lives in the
`polarGrid` block in `config.ts`.

| Parameter | Default |
| --- | --- |
| Inner radius | 2.7 |
| Ring count | 5 |
| Radial spacing | 1.128 |
| Fan start / end | -77.1° / +77.1° |
| Spoke count | 13 |
| Node radius | 0.24 |

Nodes are ordered ring-first and use stable IDs in the form
`grid-r{ringIndex}-s{spokeIndex}`. The optional conductor follows the lattice
nodes and uses the ID `conductor`.

Geometry, presentation, and semantics are separate layers:

- `hiddenNodeIds` controls visibility without removing a grid position;
- `nodeSizeMultipliers` changes radius without moving a node center;
- `nodeSections` assigns visible nodes to orchestral sections;
- `instrumentGroups` adds instrument metadata within those sections;
- `sectionHoverRegions` defines the invisible section-level pointer areas.

Hidden nodes retain their stable position and reference number. Camera and floor
bounds are derived from the complete lattice so hiding a node does not reframe
the installation. Debug mode can display the shared rings and spokes when
`polarGrid.showGuides` is enabled.

The earlier authored-coordinate, reference-diagram, wedge, warped-surface, and
gyroscope experiments have been removed from the runtime. They are preserved in
version history rather than maintained as inactive configuration paths.
